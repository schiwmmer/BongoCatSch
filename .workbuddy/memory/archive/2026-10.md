# Bingocat 归档 2026-10

### 修仙体系（crates/bongocat-pomodoro/src/cultivation/）
- 纯值状态机（时间由 PomodoroState 注入）；ADR docs/adr/0092-cultivation-ladder.md；**日界必须用本地日** view_on(now_unix, local_day)。
- 等级口径：累计等级=（境界−1）×100 + 层×10 + 阶（层0基）；元婴4层7阶=347；total_levels=1000。
- 铁律① level = level_for_growth(growth).min(realm.cap_level())。
- 铁律② spell = 根骨×19 + 仙力×26、martial = 力量×26 + 身法×15（POWER_SCALE）；无 min() 配对项。
- 缺勤：ABSENCE_LAYERS_PER_DAY=5；absence_penalty(streak, layer_growth(realm)) 按 1.2^streak×境界序号放大，扣完 max(stage_floor(realm))。
- 成长值：首场 +500、同日第 N 个 500×1.1^(N-1)×境界序号；每级 1 自由点（peak_level+allocated）。
- 潜质：doc.aptitude_tenths: Option<i32>（-100..10000 十分位），出生 -10~10；成功率=基准×1.01^N（黄500/玄420/地350/天200/神50‰，cap 995/floor 1），N=潜质+失败次数；番茄=printed×3×0.99^N；跨整百需洗髓丹 N 颗（0→1000 共 55）。
- 功法：内功每阶 3/8/12/18/27，外功 1200/2025/2700/3600/4800；掉权重 60/25/11/3.99/0.01%；失败次数按整门累计、升阶不清零；mastery_permille=[150,200,250,300,400]；可重复获得计册数 OwnedArt.copies（serde 默认1）——掉落/对手/集市三路走 keep_art_book，已有只 copies+1；grant_art 池=整品阶、排除 mastered_arts；卖书先卖多余册，修习中最后一本才拒 Training；对手 art 用独立旧表 OPPONENT_ART_MULTIPLIERS。
- 守卫 = 同境界满层裸装战力 ×120%；对手 wear() 按边际战力预检；GEAR_SHARE_PERMILLE=180。
- 战斗：命中=闪避=100+身法×10；hit_chance_permille(h,e)=800×(h/e)^0.678 钳 100..950‰；伤害=攻击力+max(法术-法抗, 法术/10)；ATB METER_FULL=1000/ROUND_CAP=30。
- 破境：胜→晋境+必得功法+40‰装备+45‰种子；败→12h 冷却+25‰掉装备。
- 探索：归来才结算（document.walk: Option<WalkInProgress>）；45‰种子/12‰装备/3‰功法/25‰遭遇，胜再掷 8‰/25‰/45‰；独立灵石 35%（3~12 枚）；提前回返无奖励、返程=已过时长/3。
- 打工（jobs.rs）：板子三单 roll_jobs(rng, tier)，tier=drop::tier_for_power(power)±1（clamp 1..10），hours 4~24；工钱=探索 purse 中值 ×1.2 ×品阶倍率[1000,1600,2400,3600,5400]；暴击 crit_chance_permille(tenths, per_ten_points)=tenths×per_ten_points/100（双倍 11‰/十点、三倍 1‰/十点，负潜质钳0）；refresh_cost(tier)=tier×50；document.work: Option<JobRun> + jobs_roll；worker tick 里 settle_work(now)；与 walk 互斥；命令 AcceptJob{slot}/RefreshJobs。
- 门内战斗的门：锁妖塔/试炼都在家打，共用 working(now)（时间感知）+ exploration_ready；trial_blocked() 四墙、proving_blocked() 三墙；进场前先 settle_walk+settle_work。accept_job 刻意用 document.work.is_some()（结算前不覆盖在跑单子，否则漏发工钱）。
- 锁妖塔横扫：trial_sweepable() = power > warden_power×3/2；trial_sweep() 清 ≤10 层、每层照常结算、耗 1 次当日次数；TrialSweepOutcome{from_floor,floors,seeds,gear,arts,stones}；Refusal::TrialNotSweepable；roll_stones 返回 u32，sweep 累计直接加。
- 品质 8 档：白→绿→蓝→紫→橙→金→红→大红绝世；multiplier 10/13/16/20/24/29/35/42；神装必带 GearEffect；升星 0..10，花费=售价一半，STAR_SUCCESS_PERMILLE[900..310]。
- 外显加成：装备 bonus: Derived（按槽位 combat_split）；内功 ArtBlueprint.bonus；Cultivation::derived() = 属性换算 + 装备外显 + 功法外显。
- 灵石集市：卖价=买价×5/10；roll_offers(day, realm, seed) 纯函数；装备 (base_points²/60+40)×rarity/10；功法=档位装备价×2.5；仙草售价=点数×14；SESSION_EARNINGS=12/场；ShopOfferView.art_ownership: Option<ArtOwnership>（Shelved 标「已有」可买副本、Mastered 换「已习得」）；已购双键 document.shop_realm+shop_day，shop_bought_valid() 双匹配，day 或 realm 变化清空。

### 构建与磁盘（细节）
- [profile.dev] incremental=false 已落地：true 时每次编译新 session，.o 永不清理（727 session/155120 文件/4.84 GiB）；改后 target 20G→7.8G，全量重建 2m28s。代价：单 crate 改一行 1.05s→2.34s。改 incremental 使所有 fingerprint 失效→先清空 target 再重建，否则新旧 rlib 并存爆盘。
- sccache 与 incremental 互斥（见 -C incremental 直接 bypass）；关掉后 sccache 才命中。
- just shebang recipe 每行缩进须严格一致（否则 inconsistent leading whitespace）；--list 只显示紧邻配方最后一行注释，长说明用 [doc('...')]。
- LAYERS_PER_REALM=10 层 vs LAYERS_PER_STAGE=100 级，满层用 threshold_for(LAYERS_PER_STAGE)；新档满层打守卫会输；apply_absence 只结算到昨天。
- 「已完成」必须 grep 核对再写 commit message；clippy -D warnings 会抓测试 useless_conversion。
