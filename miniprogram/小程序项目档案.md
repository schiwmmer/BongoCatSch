| 数据来源 | 与桌面版、网页版同一份 Rust 内核（`crates/bongocat-pomodoro` → wasm） |

## 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 前端 | 微信原生（WXML / WXSS / JS） | 无框架、无 npm 依赖，基础库 3.x |
| 后端 | 微信云开发云函数 `game` | Node 运行时，加载 `kernel.wasm`（零 import，可直接实例化） |
| 数据库 | 云开发数据库集合 `saves` | 一用户一份 JSON 文档，`_id = OPENID`，`version` 乐观锁 |
| 登录 | 微信账号（`cloud.getWXContext().OPENID`） | 无登录页、无密码、无 token |
| 计算位置 | **全部在云函数** | 客户端只发操作、只渲染快照 |

## 已用接口（云函数 `game`）

请求统一形如 `{ op, ...参数 }`，返回 `{ ok, snapshot, calendar, serverNow, version, changed, accepted, refused, completed, profile, account }`。

| 类别 | op |
| --- | --- |
| 通用 | `sync`（结算+取快照）、`profile_get`、`profile_set` |
| 番茄钟 | `create_task`、`start_task`、`pause`、`resume`、`abandon`、`set_task_done`、`update_task`、`delete_task`、`set_focus_minutes` |
| 修仙 | `explore`、`start_expedition`、`return_early`、`accept_job`、`refresh_jobs`、`tower`、`tower_sweep`、`prove`、`breakthrough` |
| 灵草园/集市 | `plant_seed`、`plant_herb_seed`、`harvest_plot`、`dig_plot`、`buy_plot`、`upgrade_garden`、`buy_from_shop`、`sell_*` |
| 功法/装备 | `select_art`、`equip_item`、`unequip_slot`、`star_equipment`、`allocate_attribute`、`select_session_mode`、`use_aptitude_herb`、`use_marrow_pill`、`acknowledge_daily_event` |
| 洞府 | `upgrade_building`、`upgrade_building_many` |

服务端硬校验：`set_focus_minutes < 25` 直接 422；时区固定 UTC+8；时间只取服务端时钟。
