# 番茄钟小程序

BongoCat 的番茄钟 + 修仙体系，做成微信小程序。四个 tab：番茄钟 / 修仙 / 功法 / 我的。

## 和网页版、桌面版是什么关系

**同一份逻辑，不是重写。** 服务端云函数里跑的就是 `crates/bongocat-pomodoro` 编译出的
`wasm32-unknown-unknown` 内核（`kernel.wasm`）——和网页版是同一个二进制，和桌面版是同一份
Rust 源码。一次突破要多少战力、集市的种子怎么摇、25 分钟折成多少修为，三边完全一致。

小程序比网页版少了一件事：**网页版把内核放在浏览器里跑，小程序把内核放在云函数里跑。**

| | 网页版 | 小程序 |
| --- | --- | --- |
| 内核在哪 | 浏览器 (`WebAssembly.instantiate`) | 云函数 (Node 里 `WebAssembly`) |
| 时钟 | 页面传入 `Date.now()` | **云函数自己的 `Date.now()`** |
| 存档 | 云库 `pomodoro_saves`（Postgres） | 云开发数据库 `saves` 集合 |
| 登录 | 邮箱验证码 | 微信账号（`OPENID`，无需令牌） |
| 谁能改数值 | 浏览器内存里的内核 | 只有云函数 |

## 防刷：三条规则都写在服务端

要求是「番茄钟本地计时，服务端校验时间，从开始到结束至少 25 分钟」。做法不是加一个
`if`，而是让**客户端根本没有计算能力**：

1. **时间只认服务器。** 每个请求都 `boot(服务器 now)` 重新结算，倒计时只按服务端时钟
   推进。请求里夹带的 `now` / `elapsed` / `serverNow` 全部不会被读。改手机时间没有用。
2. **时区固定 UTC+8。** 业务日（每日机缘、日历）不吃客户端时区，否则往东挪一天就能多
   刷一次每日结算。
3. **单次专注不得少于 25 分钟。** `set_focus_minutes` 小于 25 直接 422 拒绝；而内核
   本身只在剩余秒数被真实时间扣到 0 才结算——两条叠加，开始到结束不满 25 分钟拿不到
   任何修为。

配套的：

- 所有游戏操作（`start_task` / `explore` / `breakthrough` / `buy_from_shop` …）都只走云函数，
  一次请求一条命令，服务端逐步校验。
- 数据库集合权限必须是**仅管理端可读写**，客户端连读都读不到 `document` 字段，直接改库这条路是断的。
- 存档写入用 `version` 乐观锁，并发请求不会互相覆盖（客户端也做了请求串行）。
- 内核拒绝的操作（「人不在家」「次数已用完」等）会带 `refused: true` 回来，页面照实提示，
  不会表现成按钮点了没反应。

## 部署

1. **换 AppID**：`project.config.json` 里的 `appid` 从 `touristappid` 换成自己的正式 AppID。
2. **开通云开发**：微信开发者工具 → 云开发 → 新建环境。`app.js` 用默认环境，不用改代码。
3. **建集合**：数据库里新建集合 `saves`，权限选「仅管理端可读写」。
4. **生成内核**：仓库根目录 `just mp-kernel`（会先编译 wasm 再复制到云函数目录）。
5. **部署云函数**：右键 `cloudfunctions/game` → 上传并部署（云端安装依赖）。
   建议在云开发控制台把它的超时时间调到 **10 秒**（默认 3 秒，冷启动加载内核会紧张）。
6. **真机试**：首页应当直接进番茄钟，不再有登录页——微信身份是 `wx.cloud` 自带的。

## 本地校验（不需要 AppID）

```sh
just mp-kernel   # 编译并投放内核
just mp-check    # 三个本地检查
```

| 脚本 | 查什么 |
| --- | --- |
| `tools/selftest.js` | 用内存版 `wx-server-sdk` 跑真实云函数入口：建档、25 分钟下限、伪造时间无效、两人存档隔离、资料读写 |
| `tools/views-smoke.js` | 用真实内核快照跑一遍全部 view 构建器，扫 `undefined` / `NaN`，并比对模板字段与数据字段 |
| `tools/wxml-check.js` | 标签闭合、`wx:for` 缺 `wx:key`、`data-act` 是否有对应处理分支 |

## 已知边界

- **没有 AppID 就跑不了云函数**：本地检查覆盖逻辑与模板，但真机联调、集合权限、云函数超时只能在有 AppID 的环境里验。
- 存档是「一用户一份 JSON 文档」，和网页版同构。要做历史与对账，走 `docs/0101-pomodoro-cultivation-dw-storage.md` 那套数仓方案，不是这一版的范围。
- 头像走云存储（`avatars/` 目录），上传失败不影响存档；昵称只存服务端，不校验敏感词。
